3 Cloudflare Worker 部署准备

建议 Node 18+ LTS

wrangler 已安装并登录必须

KV 命名空间已创建必须
用于存储日程、记账数据及内容缓存
npx wrangler kv namespace create WORKBENCH_KV → 返回 id,填入 wrangler.toml
wrangler.toml 中 KV ID 已填入必须
将上一步返回的 namespace id 替换 wrangler.toml 中的 YOUR_KV_NAMESPACE_ID
binding = "WORKBENCH_KV" id = "abc123..." ← 替换这里
和风天气 API Key 已获取必须
注册和风天气开发者账号,创建应用获取 Key
免费版每日 1000 次调用,个人使用足够
和风 Key 已通过 secret 设置必须
不要明文写在 wrangler.toml 中,使用 secret 加密存储
npx wrangler secret put QWEATHER_API_KEY → 粘贴你的和风 Key → 回车
Worker 本地测试通过必须
本地 dev 模式验证 5 个 API 路由均可访问
